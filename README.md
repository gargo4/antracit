# ANTRACIT

Тёмный минималистичный ИИ-чат для учёбы и работы с текстом и картинками: стекло, синий неон, адаптив под ПК и телефон.
Next.js 15 (App Router) + TypeScript, без внешних UI-библиотек.

**Что умеет**
- 3 режима: *Чат / Решение*, *Сжатие / Расшифровка*, *Анализ по картинке* (у каждого свой системный промпт).
- Потоковый вывод, копирование в один клик, быстрые кнопки «Короче / Проще / Подробнее».
- «Ещё раз» (перегенерация), «Изменить» последнее сообщение, голосовой ввод (микрофон в Chrome/Safari/Edge).
- Формулы через KaTeX, код с подсветкой блока и копированием, таблицы.
- Поиск по чатам, переименование, группы «Сегодня / Вчера / Раньше», экспорт чата в Markdown.
- Горячие клавиши: `Enter` — отправить, `Shift+Enter` — новая строка, `Ctrl/Cmd+K` — новый чат, `Esc` — остановить ответ.
- Устанавливается на телефон как приложение (иконка, полноэкранный режим).
- Фото: галерея/камера на телефоне, выбор файла или `Ctrl+V` на ПК, превью, авто-сжатие перед отправкой.
- История чатов и разделы — локально в браузере.
- 3 API-ключа («Ключ 1», «Ключ 2», «Запасной»): ручной выбор тумблерами + автоматическое переключение.
- Цепочка моделей: если модель отдала 403/404/лимит/сбой — сервер молча берёт следующую.
- Бесплатный лимит запросов в сутки, окно «Безлимит» (заглушка под оплату), лимиты на размер текста и фото.

## Быстрый старт

```bash
npm install
cp .env.example .env.local     # впиши ключи AI_KEY_1…3 (см. комментарии в файле)
npm run dev                    # http://localhost:3000
```

Production: `npm run build && npm start`.

## Деплой (Vercel)

1. vercel.com/new → выбери репозиторий `antracit` → **Import**.
2. В *Environment Variables* добавь минимум `AI_KEY_1` (остальное — по желанию, см. `.env.example`).
3. **Deploy**. Ключи остаются на сервере и в браузер не попадают.
4. Надёжный лимит запросов (рекомендуется): Vercel → *Storage* → *Upstash Redis* (бесплатный план) → подключи к проекту.
   Переменные `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` добавятся сами; сделай *Redeploy*.

На телефоне: открой сайт → «Поделиться» → «На экран Домой» — ANTRACIT откроется как приложение.

## Как это устроено

```
src/
  app/api/chat/route.ts    единственный вызов нейросети: валидация, лимит, ротация ключей и моделей, стрим
  app/api/status/route.ts  статус слотов ключей (без самих ключей), остаток запросов, лимиты
  config/ai.server.ts      провайдер (BASE_URL), цепочка моделей, системные промпты, лимиты
  config/modes.ts          названия режимов/разделов (безопасно для клиента)
  lib/keys.ts              пул ключей × моделей, «отдых» упавших, ручной выбор
  lib/quota.ts             дневной лимит бесплатных запросов (cookie + IP-потолок; Upstash Redis или память)
  config/prompts.ts        системные промпты режимов
  components/              интерфейс (сайдбар, чат, композер, модальные окна, markdown)
```

**Ротация.** Порядок: лучшая модель × все ключи → следующая модель × все ключи → … Выбранный вручную ключ идёт первым.
Статусы `401/402/403/404/408/429/5xx` и сетевые ошибки ведут к следующей паре «ключ+модель»; неработающая пара уходит
в «отдых» (20 с – 30 мин в зависимости от причины) и не дёргается повторно. Если отказали все — пользователь видит
спокойное сообщение без технических кодов, а списанный запрос возвращается.

**Лимит бесплатных запросов**: если заданы `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` — учёт в Upstash Redis
(надёжно на Vercel), иначе — в памяти сервера (достаточно для одного сервера). Если Redis временно недоступен, чат не падает.
`FREE_REQUESTS_PER_DAY=0` отключает лимит.

**Безопасность.** Не коммить `.env.local`. Если ключ где-то засветился (чат, скриншот) — перевыпусти его.
`ADMIN_PIN` ограничивает ручной выбор ключей в настройках.

**Формулы** рендерит KaTeX (`$…$`, `$$…$$`, а также `\\(…\\)` и `\\[…\\]`); при ошибке разбора показывается читаемый текст.
